# 第 17 阶段：冻结配置与端到端 QA

## 核心改动

冻结去重全文、词形作用域 Top-1／`w=1`、条件 Top-2／`w=1` 三组配置，使用相同 GLM-5.1 与 Prompt 生成答案。研究指标为 QA Accuracy、Stale Misuse、实际输入／输出 Token 和回答延迟。

三组共享命中 Session 与写入状态；来源日期与提问日期参与回答。更新题在生成答案前标定旧值、有效新值与原文位置，评分判断最终答案是否误用旧值。三份匿名答案通过一次调用完成语义评分。

## 代码变更

- 现有 `evaluate_longmemeval_read.py` 增加 `--qa-dir` 入口，保存冻结清单、上下文、调用与逐题评分，支持断点复用。
- 回答、更新标注、评分分别统计实际 usage；正确率报告有效题数和 Wilson 区间，配置差异报告配对结果。
- 现有测试增加四项用例。完整代码对照见[逐文件报告](../details/17-冻结配置与端到端QA逐文件交付.md)，差异见[批次补丁](../patches/17-冻结配置与端到端QA.patch)。
- 评分解析统一处理 JSON 围栏和已观察到的字段拼写；续跑补齐缺失评分，调用日志保存每次响应与请求摘要。

## 验证结果

指定回归 **165 passed**，Ruff 与格式检查通过。500 题的 1,500 份上下文已准备；Top-1／Top-2 逐题复现第 16 批上下文估算成本。

500 题共完成 1,500 份回答，使用固定 GLM-5.1 生成并匿名评分。成本为每题回答的实际输入与输出 Token；延迟为回答调用墙钟耗时中位数。

| 配置 | QA 正确率 | 过期信息误用 | 输入 Token | 输出 Token | 总 Token | 延迟 / 秒 |
|---|---:|---:|---:|---:|---:|---:|
| 去重全文 | 401/500（80.2%） | 4/54（7.41%） | 6,311.85 | 43.49 | 6,355.34 | 5.49 |
| Top-1，w=1 | 404/500（80.8%） | 6/54（11.11%） | 5,792.99 | 42.31 | 5,835.30 | 5.70 |
| 条件 Top-2，w=1 | 394/500（78.8%） | 5/54（9.26%） | 5,906.77 | 43.83 | 5,950.60 | 5.73 |

Top-1 较全文省实际回答 Token **8.18%**，正确率差 +0.6 个百分点，配对 95% 区间 −2.75～+3.95 个百分点；Top-2 省 6.37%，正确率差 −1.4 个百分点，区间 −4.66～+1.86。Top-1 的成本收益伴随过期误用增加，三组调用延迟相近。

按历史固定 ID 对齐，Top-1 在原 180 题为 153/180（85.00%），后加入 180 题为 150/180（83.33%）；8 月 21 日对应成绩为 139/180（77.22%）和 140/180（77.78%）。原 360 题从 279/360（77.50%）变为 303/360（84.17%）。[历史同题对照](../results/17-历史180与360题同题对照.json)保留各版本分数与逐题转移；各阶段回答链路和评分 Prompt 的变化一并记录。

78 道更新题经新旧原文核对及历史问题时点复核，54 道进入误用评价，三组均完成 54 道评分。该批为已参与配置探索的 Oracle 500 题端到端复测；生成与评分共用 GLM-5.1。原接口凭据失效后，按授权在同一接口与模型下续跑；全部调用记录保留。分组和逐题记录见[完整结果](../results/17-端到端QA逐题结果.json)，核对见[执行复核](../results/17-QA执行复核.json)，运行口径见[复现说明](../reproduction.md)。
