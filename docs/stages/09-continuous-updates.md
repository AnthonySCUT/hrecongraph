# 第九批：连续更新与增量记忆束

## 核心改动

后续对话只提交新增或变化维度的 `source_spans`；控制器继承其余维度，重建当前四维证据束并同步 M1/M2。连续回放覆盖新增事实、补充限定与原因、局部修改、替代、删除和检索读取。

```text
本轮操作 + 变化维度证据
  -> 继承未变化维度
  -> 同步 M1/M2 与图来源
  -> 检索读取与指标计算
```

## 代码变更

- `memory_unit.py`：增量合并与指定维度替换。
- `manager.py`：追加证据、局部更新、替代和删除共用记忆束入口。
- `semantic_state.py`：随限定和原因证据刷新状态。
- 连续回放测试同时检查缓存读取与新 controller 来源恢复。
