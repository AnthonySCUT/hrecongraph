# 第十三批：重复渲染修复与依赖作用域消融

## 核心改动

分别检查图事实重复渲染、窗口扩展对象和自动依赖词面筛选。来源正文已包含图事实时复用正文；以事实锚点为窗口中心开展对照；自动依赖按问题或事实的有效词面重合筛选。同步重跑去重后的 Top-1 与条件 Top-2 配置。

## 代码变更

- `relinking.py`：增加事实窗口和依赖选择实验参数，并避免来源正文与图事实重复输出。
- `evaluate_longmemeval_read.py`：记录远端支持轮次、依赖新增轮次、实际渲染 Token、题型统计和 Pareto 配置。
- `evaluate_read_context.py`：复核机制样本在依赖筛选下的证据保留。
