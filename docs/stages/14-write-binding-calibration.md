# 第 14 阶段：写入绑定校准

## 核心改动

比较原子串、英文词界、词界加事实作用域三种写入规则，保持原词面检索、每 Session 的 Top-1 事实锚点、窗口与去重装配一致。默认继续使用原子串规则，两种候选用于消融。

本批先验证 16 个机制样本，再探索性复测 LongMemEval Oracle 500 题。支持标注在装配后参与评分，固定检索一致性与第 13 批基线复现均通过。

## 代码变更

- `semantic_state.py`：触发词和派生语义字段共用匹配规则；自动依赖可按同段或有效实词重合绑定到事实段落。
- `memory_unit.py` / `relinking.py`：用 `fact_starts` 保存原文事实偏移，读取时按命中事实展开所属依赖。
- 两份读取评测脚本：增加 `--binding-calibration`，输出 12 组配置、依赖移除账本、距离分组和联合 Pareto。
- 两份测试：增加四项核心测试，覆盖词界、来源归属、固定检索与远端省略表达。

完整代码对照与测试见[逐文件报告](../details/14-写入绑定校准逐文件交付.md)，完整七文件改动见[批次差异](../patches/14-写入绑定校准.patch)。

## 验证结果

指定回归 **153 passed**；Ruff check、format check、Git 差异检查通过。

16 个机制样本在 `w=1` 下均保留 35 / 35 段必要证据、完成 16 / 16 探针；事实作用域配置平均 Token 从 59.25 降至 53.44。

500 题中，479 题标注了 896 条支持轮次。下表均使用 `w=1`：

| 规则 | 平均 Token | 支持保留 | 整体 Micro | 完整题数 / 479 |
|---|---:|---:|---:|---:|
| 原子串 | 6,606.28 | 873 / 896 | 97.43% | 462 |
| 英文词界 | 6,057.00 | 842 / 896 | 93.97% | 436 |
| 词界 + 作用域 | 5,880.24 | 840 / 896 | 93.75% | 434 |

两种候选分别节省 8.31% / 10.99% Token，净损失 31 / 33 条支持。远端参考证据从 159 / 159 降至 143 / 159。主要损失发生在跨会话与时间推理题；词形遗漏、事实锚点覆盖和依赖窗口联动是下一阶段重点。

在整体 Micro 95% 参考线下，最低成本配置为作用域 `w=2`：6,501.87 Token、853 / 896 支持、95.20% 召回。所有配置的 Micro / Macro、分组、索引和损失记录见[500 题结果](../results/14-LongMemEval写入绑定校准.json)及[诊断汇总](../results/14-写入绑定校准汇总.json)；小样本见[机制样本结果](../results/14-机制样本写入绑定校准.json)。
