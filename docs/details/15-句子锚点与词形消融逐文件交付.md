# 第十五批：句子锚点与词形消融

## 核心改动

本批检验两项假设：句子级事实锚点能否减少无关依赖，合法词形补全能否恢复第 14 批词界规则损失的证据。采用三种绑定规则 × 两种事实粒度的配对实验。

| 因素 | 取值 |
|---|---|
| 绑定规则 | 原子串 `substring`、词界作用域 `fact_scope`、词形作用域 `word_form_scope` |
| 事实粒度 | 原轮次事实 / 段落索引 `paragraph`、句子事实 / 句子索引 `sentence` |
| 读取配置 | 全文、证据束 `w=0/1/2` |

三种规则共用命中 Session 和 Top-1 原始轮次；句子方案只在该轮内部选取有效问题词重合最多的一句，并列取最早句子。16 个机制样本保留原命中事实段落，在该段内选择句子。六组的固定检索核对通过。

每个句子保留原文 `start/end`；读取上下文保留 `source_fact_indices` 和 `source_fact_spans`，结果文件同时记录 `turn_index`、原文偏移和图事实。正文装配与窗口继续采用原始轮次，消息内部换行保持在所属轮次内。问题参与读取定位；答案和支持标注参与装配后的评分。

实测得到两个不同结论：词形补全改善了作用域候选；句子锚点进一步收缩作用域后，成本和召回同步下降。默认配置继续使用原子串与原粒度。

### 数学与数据流

在已选轮次 $u$ 的句子集合 $S(u)$ 中，以现有分词器的有效词集合 $T$ 选择：

\[
s^*=\mathop{\arg\max}_{s\in S(u)}|T(s)\cap T(q)|.
\]

将 $s^*$ 原始起点作为依赖归属查询值：写入记录的 `fact_starts` 包含该偏移时，读取展开相应依赖；随后按原始轮次扩窗、并集去重、原序输出。原粒度方案沿用选中轮次内的事实段落。

句子索引按中英文句末标点和换行切分，英文句末标点后要求空白或文本结束，小数点保持在原句内。词形表包含 `recent/recently`、`current/currently`、`increase/decrease/connect/route` 的常见词形；采用完整词边界匹配。

```text
固定 Session 与 Top-1 Turn
  -> 原轮事实 / 轮内最高重合句子
  -> 激活事实原文偏移
  -> 展开所属限定、路径与因果证据
  -> 原始轮次窗口与正文装配
  -> 支持证据评分、Token 与渲染计时
```

```python
async def build_context(
    case: dict,
    *,
    max_fact_anchors: int = 1,
    binding_rule: str = 'substring',
    fact_granularity: str = 'paragraph',
) -> HierarchicalMemoryContext:
    """Use only question/source text to build one fixed lexical graph adapter."""
    now = utc_now()
    writer = HReConGraphMemory(
        semantic_state_constructor=SemanticStateConstructor(
            binding_rule, fact_granularity=fact_granularity
        )
    )
    episodes, edges, states = [], [], []
    units, fact_indices, fact_spans = {}, {}, {}
    for session_index in hit_session_indexes(case['haystack_sessions'], case['question']):
        session = case['haystack_sessions'][session_index]
        memory = UnifiedMemoryUnit(
            memory_id=f'lm-{case["question_id"]}-{session_index}',
            user_id='eval',
            layer='M1',
            lifecycle_status='active_short_term',
            raw_content=session_text(session),
        )
        await writer.add_memory(memory)
        episode = EpisodicNode(
            uuid=f'episode-{case["question_id"]}-{session_index}',
            name=case['question_id'],
            group_id='user:eval',
            source=EpisodeType.text,
            source_description='LongMemEval dialogue session',
            content=GraphitiMemoryStore(None)._episode_body(memory),
            valid_at=now,
        )
        selected = fact_turn_indexes(session, case['question'], max_anchors=max_fact_anchors)
        units[episode.uuid] = [turn_text(message) for message in session]
        fact_indices[episode.uuid] = selected
        for anchor_index, turn_index in enumerate(selected):
            fact = turn_text(session[turn_index])
            if fact_granularity == 'sentence':
                start = sum(len(turn_text(turn)) + 2 for turn in session[:turn_index])
                candidates = [
                    span
                    for span in memory.source_spans
                    if span.field == 'fact' and start <= span.start < start + len(fact)
                ]
                anchor = select_fact_span(candidates, case['question'])
                fact_spans.setdefault(episode.uuid, []).append(anchor)
                fact = anchor.text
            edges.append(
                EntityEdge(
                    uuid=f'{episode.uuid}-edge' + (f'-{anchor_index}' if anchor_index else ''),
                    created_at=now,
                    group_id='user:eval',
                    source_node_uuid=f'{episode.uuid}-source',
                    target_node_uuid=f'{episode.uuid}-target',
                    name='RELEVANT_TURN',
                    fact=fact,
                    episodes=[episode.uuid],
                )
            )
        episodes.append(episode)
        states.append(writer.semantic_states[memory.semantic_state_id])
    return HierarchicalMemoryContext(
        query=case['question'],
        selected_layers=['M1'],
        graph_edges=edges,
        semantic_states=states,
        source_episodes=episodes,
        source_units=units,
        source_fact_indices=fact_indices,
```

新增句子索引函数：

```python
    @classmethod
    def _sentences(cls, text: str, evidence_ids: list[str]) -> list[SourceSpan]:
        """Index source sentences with offsets in the original interaction."""
        sentences = []
        for paragraph in cls._paragraphs(text, evidence_ids):
            for match in re.finditer(
                r'.+?(?:[。！？]|[.!?](?=\s|$)|\n|$)', paragraph.text, flags=re.S
            ):
                raw = match.group()
                value = raw.strip()
                if value:
                    start = paragraph.start + match.start() + len(raw) - len(raw.lstrip())
                    sentences.append(
                        SourceSpan(
                            evidence_id=paragraph.evidence_id,
                            text=value,
                            start=start,
                            end=start + len(value),
                            field='fact',
                        )
                    )
        return sentences
```

```python
def select_fact_span(spans: list[SourceSpan], query: str) -> SourceSpan:
    """Keep the earliest sentence with the most distinct query-word matches."""
    ranker = MemoryUtilityRanker()
    words = ranker.tokenize(query)
    return max(spans, key=lambda span: len(ranker.tokenize(span.text) & words))
```
