# 10：自然对话证据绑定与读取去重

日期：2026-10-21。工作副本：`26-10-16-逐代码审核`。

## 核心改动

本批把第八、九批依赖的外部四维绑定推进到自然文本写入链路，并优化证据束读取：

- `SemanticStateConstructor` 按原文段落生成缺失的 `fact` 锚点。
- 检测明确路径、限定、因果触发词，生成 `path / constraint / causal` 段落锚点。
- 已有显式四维绑定优先参与语义状态构造；自动锚点负责原文定位。
- `evidence_bundle` 按图事实与原文事实锚点的词面重合选择段落，并展开同一记忆束的限定、路径、因果依赖。
- M1/M2 同源副本的相同 `edge.fact` 与来源正文按内容去重，减少重复读取文本。

数据流：

```text
自然交互
  -> 段落切分与四维锚定
  -> source_spans / semantic_state / episode envelope
  -> 图事实词面定位目标段落
  -> 展开四维依赖并去除同源重复
  -> evidence_bundle
```

## 代码变更

### `h_recongraph/memory/semantic_state.py`

改前：自然文本主要生成 `cause / condition / temporal_scope` 等语义槽，`fact` 与 `path` 缺少自动原文锚点。

改后：在语义状态构造前调用 `_bind_missing_dimensions()`。该方法以原文段落为单位生成锚点：

```python
if 'fact' not in bound:
    spans.extend(
        span.model_copy(update={'field': 'fact'}, deep=True)
        for span in paragraphs
    )
if 'path' not in bound:
    spans.extend(
        span.model_copy(update={'field': 'path'}, deep=True)
        for span in paragraphs
        if self._contains_marker(span.text, self.PATH_MARKERS)
    )
```

`_paragraphs()` 同时保存段落文本、原文起止位置和证据 ID。后续 Graphiti 关系事实改写时，读取端可通过这些位置找到原文段落。

### `h_recongraph/memory/relinking.py`

改前：证据束按所有事实和语义 span 直接收集段落；图事实改写时依赖原文字面命中。

改后：对每条图事实执行两级定位：先查原文完整命中；再按图事实与段落的词面交集选择最高匹配段落。选中事实段落后，继续加入同一记忆束中 constraint、path、causal span 所在段落。

```python
fact_tokens = self._tokens(fact)
overlaps = [
    (len(fact_tokens.intersection(self._tokens(paragraph))), index)
    for index, paragraph in enumerate(paragraphs)
]
score, index = max(overlaps, default=(0, 0))
if score:
    selected.add(index)
```

证据束模式新增按正文内容的来源去重，以及按 `edge.fact` 的关系去重；全文模式保留 M1/M2 的完整来源记录。
