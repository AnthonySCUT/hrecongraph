# 08：记忆束局部更新与改写裁剪

日期：2026-10-20。工作副本：`26-10-16-逐代码审核`。承接第六、七批的证据片段读取与 16 样本配对实验。

## 核心改动

写入、更新和读取共享同一个单位：**事实＋限定＋路径＋因果的原文证据束**。四维证据沿 `source_spans → semantic_state → episode envelope → source_episodes → 读取段落` 流转。

- 新增 `add_memory(memory)` 与 `update_memory(memory_id, operation=..., replacement=...)`。调用方提交明确操作与完整替换束，控制器执行局部写入。
- `modify` 同步修改目标的 M1/M2 副本；`supersede` 写入新 ID、版本与前驱；`delete` 撤去该束的来源与专属关系。关联 M0 原始副本同步退出当前读取。
- 通过现有 `promoted_from / consolidated_from` 找到同一束的层级关联；其他记忆保持原值。
- 图边按来源维护：有其他来源支持的共享边保留，其余来源引用和专属边随目标束撤去。
- 关系改写时，使用有效 `field='fact'` 原文锚点定位事实段落，再合并限定、路径、因果锚点，输出完整相关段落。

| 操作 | 定位与写入单位 | 结果 |
|---|---|---|
| add | 新记忆束 | 保存正文、证据、语义状态与图关联 |
| modify | 目标束及其层级关联 | 保持各层 ID，版本递增，以新正文和完整证据束替换 |
| supersede | 目标束及其层级关联 → 新束 | 旧束 revised，新束记录 supersedes 和递增版本 |
| delete | 目标束及其层级关联 | 撤去来源与专属图边，状态置 deleted，清除相应语义状态和 M0 副本 |

### manager.py：写入与局部操作

`add_interaction()` 增加可选的 `source_spans` 输入，在 M0 写入时携带证据。M1 提升和 M2 巩固均调用以下统一入口。

```python
    async def add_memory(self, memory: UnifiedMemoryUnit) -> UnifiedMemoryUnit:
        """Write one M1/M2 bundle with its fact, constraint, path and causal evidence."""
        memory.evidence_ids = list(
            dict.fromkeys(
                [*memory.evidence_ids, *(span.evidence_id for span in memory.source_spans)]
            )
        )
        state = self.semantic_state_constructor.construct(memory)
        memory.semantic_state_id = state.state_id
        memory.semantic_state = state.model_dump(mode='json')
        memory.source_spans = [
            *(span for span in memory.source_spans if span.field == 'raw'),
            *state.source_spans,
        ]
        target = self.short_term_memories if memory.layer == 'M1' else self.long_term_memories
        target[memory.memory_id] = memory
        self.semantic_states[state.state_id] = state
        if self.store is not None:
            await self.store.add_memory(memory)
        return memory
```

局部操作首先沿层级来源关系取得目标束的副本，再更新相应正文、证据和图来源。修改时重建语义状态，旧时间范围与旧原因随完整替换束一起更新。

```python
    async def update_memory(
        self,
        memory_id: str,
        *,
        operation: Literal['modify', 'supersede', 'delete'],
        replacement: UnifiedMemoryUnit | None = None,
    ) -> UnifiedMemoryUnit | None:
        """Apply a local operation to a bundle and its M0/M1/M2 lineage."""
        memories = {**self.short_term_memories, **self.long_term_memories}
        target = memories[memory_id]
        family_ids = {memory_id}
        lineage = [
            (memory.memory_id, parent)
            for memory in memories.values()
            for parent in (
                memory.metadata.get('promoted_from'),
                memory.metadata.get('consolidated_from'),
            )
            if parent
        ]
        while True:
            expanded = family_ids | {
                item
                for child, parent in lineage
                if child in family_ids or parent in family_ids
                for item in (child, parent)
            }
            if expanded == family_ids:
                break
            family_ids = expanded
        family = [memory for memory in memories.values() if memory.memory_id in family_ids]
        if self.store is not None:
            await self.store.remove_memories(family)
        self.buffer.remove_many(family_ids)
        for memory in family:
            memory.lifecycle_status = 'deleted' if operation == 'delete' else 'revised'
            self.semantic_states.pop(memory.semantic_state_id, None)
        if operation == 'delete':
            return None
        if operation == 'supersede':
            replacement.version = target.version + 1
            replacement.supersedes = list(dict.fromkeys([*target.supersedes, target.memory_id]))
            return await self.add_memory(replacement)
        updated = {}
        for memory in family:
            revised = replacement.model_copy(deep=True)
            revised.memory_id = memory.memory_id
            revised.layer = memory.layer
            revised.ttl = memory.ttl
            revised.lifecycle_status = (
                'active_short_term' if memory.layer == 'M1' else 'consolidated'
            )
            revised.version = memory.version + 1
            revised.supersedes = list(memory.supersedes)
            revised.graph_binding = GraphBinding()
            revised.metadata = {
                **replacement.metadata,
                **{
                    key: memory.metadata[key]
                    for key in ('promoted_from', 'consolidated_from')
                    if key in memory.metadata
                },
            }
            updated[memory.memory_id] = await self.add_memory(revised)
        return updated[memory_id]
```

`consolidate()` 继续处理当前有效 M1；`_consolidate_memory()` 保留原有评分和版本判断，并复用 `add_memory()` 保存整束证据。

### semantic_state.py：保留四维来源依赖

改前，`construct()` 从空证据列表开始。改后继承传入的细粒度证据，`raw` 全文来源继续保存在记忆单元中。

```python
spans = [span.model_copy(deep=True) for span in memory.source_spans if span.field != 'raw']
```

构造结果按 `evidence_id + field + text + start + end` 去重。显式维度使用 `fact / constraint / path / causal`，已有语义字段继续使用 `cause / condition / validity` 等名称。

配对实验还发现：原有原因规则会跨越句号和段落，把后续办公服务段落接进原因字段。本批将原因截取边界补为逗号、句号与换行，并对齐截取偏移；相关原文段落因此得到完整保留和准确定位。

### graphiti_store.py：局部撤去来源与专属边

改前，适配器提供写入与读取接口。改后增加以下方法：读取目标束引用的 episodes 和其中的边，撤去目标来源；共享边保存剩余来源，专属边与目标 episode 删除。

```python
    async def remove_memories(self, memories: list[UnifiedMemoryUnit]) -> None:
        """Detach bundle sources while retaining edges supported by other sources."""
        episode_ids = list(
            dict.fromkeys(eid for memory in memories for eid in self.episode_ids(memory))
        )
        if not episode_ids:
            return
        driver = self.graphiti.driver
        episodes = await EpisodicNode.get_by_uuids(driver, episode_ids)
        edge_ids = list(dict.fromkeys(eid for episode in episodes for eid in episode.entity_edges))
        edges = await EntityEdge.get_by_uuids(driver, edge_ids) if edge_ids else []
        for edge in edges:
        if not set(episode_ids).intersection(edge.episodes):
            continue
            edge.episodes = [eid for eid in edge.episodes if eid not in episode_ids]
            if edge.episodes:
                await edge.save(driver)
            else:
                await edge.delete(driver)
        for episode in episodes:
            await episode.delete(driver)
```

`_episode_body()` 继续保存正文、语义状态与 `source_spans`，另保存 `promoted_from / consolidated_from`。`_restore_source_memories()` 恢复这两个字段，延续同一束的层级关系。

### relinking.py：关系改写的前后对照

改前：

```python
    def _source_bundle(self, episode: EpisodicNode) -> str:
        """Keep complete paragraphs anchored by retrieved facts and semantic evidence."""
        content = self._source_text(episode.content)
        facts = [edge.fact for edge in self.graph_edges if episode.uuid in edge.episodes]
        if not facts or any(fact not in content for fact in facts):
            return content
        anchors = [
            *facts,
            *(
                span.text
                for state in self.semantic_states
                for span in state.source_spans
                if span.text and span.text in content

        ]
        return '\n\n'.join(
            paragraph
            for paragraph in re.split(r'\n\s*\n', content)
            if any(anchor in paragraph for anchor in anchors)
        )

    @staticmethod
```

改后：

```python
    def _source_bundle(self, episode: EpisodicNode) -> str:
        """Keep complete paragraphs anchored by retrieved facts and semantic evidence."""
        content = self._source_text(episode.content)
        facts = [edge.fact for edge in self.graph_edges if episode.uuid in edge.episodes]
        spans = [
            span
            for state in self.semantic_states
            for span in state.source_spans
            if span.field != 'raw' and span.text and span.text in content
        ]
        # A bound fact anchor also locates evidence when the graph fact is paraphrased.
        fact_anchors = [span.text for span in spans if span.field == 'fact']
        if not facts or (any(fact not in content for fact in facts) and not fact_anchors):
            return content
        anchors = [
            *(fact for fact in facts if fact in content),
            *(span.text for span in spans),
        ]
        return '\n\n'.join(
            paragraph
            for paragraph in re.split(r'\n\s*\n', content)
            if any(anchor in paragraph for anchor in anchors)
        )

    @staticmethod
```

例如图边为 `Project Atlas uses Redis`，原文为 `Project Atlas relies on Redis.`；写入时保存后者的 fact 锚点，并绑定 `Only during October.` 等依赖。读取保留这两个原文段落，过滤办公服务段落。

### 16 个样本配对实验

沿用第七批的 16 个固定机制样本：四维各 4 个，分别覆盖同段、跨段已有绑定、跨段待补绑定与关系改写。原有样本文件和评分字段保持原样；新文件单独列出根据原文标注的事实与依赖段落。写入输入采用该独立绑定文件，问题、必要证据清单和答案用于读出评分。

实验将完整绑定提交到 `add_memory()`，随后用 envelope 序列化并从命中来源恢复状态，最后比较全文与片段模式。图边使用固定样本中的关系。

| 原有绑定 | 片段 | 88.57%（31/35） | 12/16 | 12/16 | 2896 |
| 完整写入绑定 | 全文 | 100%（35/35） | 16/16 | 16/16 | 4651 |
| 完整写入绑定 | 片段 | 100%（35/35） | 16/16 | 16/16 | 2651 |
