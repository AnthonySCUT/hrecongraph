# 07 忠实性与读取成本对照

## 核心改动

建立固定上下文的配对实验：同一问题、同一已选关系、同一来源和语义证据分别运行 full_source 与 evidence_bundle。比较必要证据保留、完整样本数、确定性答案探针、字符数和文本组装时间。

数据为本轮人工设计的 16 个机制样本：事实、约束、路径、因果各 4 个。每个维度包含同段信息、已有跨段锚点、缺少跨段锚点、关系改写四种情形；相同内容的版式与锚点对照用于定位机制原因。

本次实测发现：已有锚点的跨段信息得到保留；四个缺少锚点的样本出现遗漏。因此流程停在第七批结果审查，第八批的业务修改等待审查决定。当前默认读取方式保持 full_source。

## 代码变更

- `h_recongraph/examples/read_context_cases.json`：显式记录 question、source、所选 facts、已有 spans、必要证据 required 和答案探针。
- `h_recongraph/examples/evaluate_read_context.py`：构造真实 EpisodicNode / EntityEdge / MemorySemanticState，调用当前 render_text，保存逐样本结果与四维汇总。
- `tests/test_h_recongraph_retrieval.py`：增加两个测试，校验实验统计及补充跨段 cause 证据后的结果变化。
- `逐文件审核记录/07-读取对照结果.json`：保存 32 条配对结果；每个模式、每个样本重复组装 100 次测量耗时。

指标：

```text
必要证据保留率 = 出现在最终文本中的 required 条目数 / required 条目总数
完整样本数 = 全部 required 条目均保留的样本数
答案探针 = 用样本预设正则从文本提取答案，与 expected_answer 比较
成本单位 = Unicode 字符数
延迟范围 = render_text 文本组装
```

答案探针用于检查特定信息是否可读出。模型回答准确率由后续真实问答实验单独测量。

实验脚本完整代码：

```python
"""Paired evidence-retention and text-cost evaluation on fixed reading contexts."""

import argparse
import json
import re
from pathlib import Path
from statistics import median
from time import perf_counter

from graphiti_core.edges import EntityEdge
from graphiti_core.nodes import EpisodeType, EpisodicNode
from graphiti_core.utils.datetime_utils import utc_now
from h_recongraph.memory.relinking import HierarchicalMemoryContext
from h_recongraph.schemas.memory_unit import SourceSpan
from h_recongraph.schemas.semantic_state import MemorySemanticState


def build_context(case: dict) -> HierarchicalMemoryContext:
    now = utc_now()
    sources = [
        EpisodicNode(
            uuid=source['id'],
            name=case['id'],
            group_id='user:eval',
            source=EpisodeType.text,
            source_description='fixed reading case',
            content=source['content'],
            valid_at=now,
        )
        for source in case['sources']
    ]
    edges = [
        EntityEdge(
            uuid=fact['id'],
            created_at=now,
            group_id='user:eval',
            source_node_uuid=f'node-{i}',
            target_node_uuid=f'node-{i + 1}',
            name='RELATION',
            fact=fact['text'],
            episodes=[fact['source']],
        )
        for i, fact in enumerate(case['facts'])
    ]
    spans = [SourceSpan(evidence_id=case['id'], **span) for span in case['spans']]
    states = (
        [
            MemorySemanticState(
                edge_or_subgraph_id=case['id'],
                source_spans=spans,
                state_type='evidence_supported',
            )
        ]
        if spans
        else []
    )
    return HierarchicalMemoryContext(
        query=case['question'],
        selected_layers=['M1', 'M2'],
        graph_edges=edges,
        semantic_states=states,
        source_episodes=sources,
    )


def evaluate_cases(cases: list[dict], repeats: int = 100) -> dict:
    rows = []
    for case in cases:
        context = build_context(case)
        for mode in ('full_source', 'evidence_bundle'):
            durations = []
            for _ in range(repeats):
                start = perf_counter()
                text = context.render_text(mode)
                durations.append((perf_counter() - start) * 1000)
            missing = [item for item in case['required'] if item not in text]
            match = re.search(case['answer_pattern'], text)
            answer = match.group('answer') if match else ''
            rows.append(
                {
                    'case_id': case['id'],
                    'dimension': case['dimension'],
                    'mode': mode,
                    'chars': len(text),
                    'required_count': len(case['required']),
                    'retained_count': len(case['required']) - len(missing),
                    'complete': not missing,
                    'missing': missing,
                    'probe_answer': answer,
                    'probe_correct': answer == case['expected_answer'],
                    'render_median_ms': median(durations),
                }
            )
    summary = {}
    for mode in ('full_source', 'evidence_bundle'):
        selected = [row for row in rows if row['mode'] == mode]
        summary[mode] = {
            'case_count': len(selected),
            'total_chars': sum(row['chars'] for row in selected),
            'evidence_retention': sum(row['retained_count'] for row in selected)
            / sum(row['required_count'] for row in selected),
            'complete_cases': sum(row['complete'] for row in selected),
            'extractive_probe_correct': sum(row['probe_correct'] for row in selected),
            'render_median_ms': median(row['render_median_ms'] for row in selected),
            'dimensions': {
                dimension: {
                    'complete': sum(
                        row['complete'] for row in selected if row['dimension'] == dimension
                    ),
                    'count': sum(row['dimension'] == dimension for row in selected),
                }
                for dimension in ('fact', 'constraint', 'path', 'causal')
            },
        }
    return {
        'protocol': 'fixed-context evidence retention and deterministic extractive probes',
        'length_unit': 'unicode_characters',
        'latency_scope': 'render_text only',
        'timing_repeats': repeats,
        'summary': summary,
        'rows': rows,
    }


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument(
        '--cases', type=Path, default=Path(__file__).with_name('read_context_cases.json')
    )
    parser.add_argument('--repeats', type=int, default=100)
    parser.add_argument('--output-json', type=Path, required=True)
    args = parser.parse_args()
    cases = json.loads(args.cases.read_text(encoding='utf-8'))
    result = evaluate_cases(cases, args.repeats)
    args.output_json.parent.mkdir(parents=True, exist_ok=True)
    args.output_json.write_text(json.dumps(result, ensure_ascii=False, indent=2), encoding='utf-8')
    print(json.dumps(result['summary'], ensure_ascii=False, indent=2))


if __name__ == '__main__':
    main()
```

## 验证结果

| 指标 | full_source | evidence_bundle |
|---|---:|---:|
| 总字符数 | 4557 | 2896 |
| 必要证据保留率 | 100.00% | 88.57% |
| 完整证据样本 | 16/16 | 12/16 |
| 确定性答案探针 | 16/16 | 12/16 |
| 组装中位耗时 | 0.002450 ms | 0.004250 ms |

字符数减少 **36.45%**。计时值为各样本 100 次重复中位数的中位数。四个维度的完整样本数均从 4/4 变为 3/4。

| 失去完整证据的样本 | 遗漏原文 |
|---|---|
| fact-unanchored | The cache operator is Team Blue. |
| constraint-unanchored | This setting applies only during October. |
| path-unanchored | The cache serves the dashboard |
| causal-unanchored | The reason is that the legacy client requires it. |

消融验证：给 causal-unanchored 补充已有 schema 支持的 cause span 后，原因段与答案探针恢复。这定位了“跨段证据表示是否充分”的影响。
