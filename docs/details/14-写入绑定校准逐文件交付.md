# 第十四批：写入绑定规则校准

## 核心改动

本批检验：收紧写入依赖的触发与事实归属，能以多少上下文成本保留多少必要证据。采用三种规则、四种读取配置，先运行 16 个机制样本，再探索性复测 LongMemEval Oracle 500 题。

| 写入规则 | 实现 |
|---|---|
| `substring` | 保留原子串匹配，作为默认基线 |
| `word_boundary` | 英文触发词按完整词匹配，中文沿用原规则 |
| `fact_scope` | 在词界规则上，将自动依赖绑定到同段或有有效实词重合的事实段落 |

检索保持原词面适配：按问题选取 Session，每个命中 Session 取有效重合词最多的 Top-1 原始轮次，并构造 `RELEVANT_TURN` 图关系。三组规则共用命中 Session、事实轮次及读取配置，固定检索一致性检查通过。读取比较 `full_source` 与 `evidence_bundle(w=0/1/2)`，统一采用依赖展开后扩窗、正文去重。

写入规则仅读取来源文本。问题用于检索；`answer`、`has_answer` 和机制样本必要片段用于装配后的评分。本轮 500 题继续承担配置探索，下一阶段以词形和细粒度事实锚点为研究对象。

结果显示，词界校准与作用域收缩带来成本—召回权衡：`w=1` 下平均 Token 从 6,606.28 降至 6,057.00 / 5,880.24，支持轮次从 873 降至 842 / 840。因此保留 `substring` 默认值，将两种候选作为显式消融选项。

### 绑定逻辑

对依赖片段所在段落记为 $d$，事实段落记为 $f$，现有分词器的有效词集合记为 $T$。候选归属规则为：

\[
A(d)=\{\operatorname{start}(f)\mid f=d\;\lor\;T(f)\cap T(d)\ne\varnothing\}.
\]

写入将 $A(d)$ 保存为 `fact_starts`；读取在命中事实段落集合 $F$ 中选择满足 $A(d)\cap F\ne\varnothing$ 的依赖。显式给定的证据保持原绑定。原始段落偏移与原始 Turn Index 分别承担绑定与评分定位。

```python
    def _marker_index(self, text: str, marker: str) -> int:
        if self.binding_rule == 'substring' or not marker.isascii():
            return text.lower().find(marker.lower())
        match = re.search(r'(?<!\w)' + re.escape(marker) + r'(?!\w)', text, flags=re.I)
        return match.start() if match else -1
```


```python
    def _bind_fact_scopes(
        self, text: str, memory: UnifiedMemoryUnit, spans: list[SourceSpan]
    ) -> None:
        """Attach automatic dependencies to paragraphs sharing source content words."""
        paragraphs = self._paragraphs(text, memory.evidence_ids)
        ranker = MemoryUtilityRanker()
        tokens = [
            ranker.tokenize(re.sub(r'^(?:user|assistant|system):\s*', '', span.text, flags=re.I))
            for span in paragraphs
        ]
        explicit = {(span.field, span.start, span.end, span.text) for span in memory.source_spans}
        for span in spans:
            if span.field == 'fact' or (span.field, span.start, span.end, span.text) in explicit:
                continue
            owner = next(
                (
                    i
                    for i, paragraph in enumerate(paragraphs)
                    if paragraph.start <= span.start < paragraph.end
                ),
                None,
            )
            if owner is not None:
                span.fact_starts = [
                    paragraph.start
                    for i, paragraph in enumerate(paragraphs)
                    if i == owner or tokens[owner] & tokens[i]
                ]
```

```python
async def evaluate_binding_calibration(cases: list[dict], *, repeats: int = 3) -> dict:
    results = {
        rule: await evaluate_cases(
            cases, repeats=repeats, window_sizes=(0, 1, 2), binding_rule=rule

    retrieval = [
        [
            (
                item['question_id'],
                item['hit_session_indices'],
                [
                    (binding['graph_fact_turn_indices'], binding['graph_facts'])
                    for binding in item['source_bindings']
                ],
            )
            for item in result['fixed_retrieval']
        ]
        for result in results.values()
    ]
    summaries = {
        f'{rule}/{name}': summary
        for rule, result in results.items()
        for name, summary in result['summary'].items()

        'experiment_role': 'exploratory reuse of oracle 500',
        'fixed_retrieval_equal': all(item == retrieval[0] for item in retrieval),
        'binding_calibration': results,
        'comparison_w1': binding_diagnostic(results),
        'joint_pareto': pareto_analysis(summaries, list(summaries)),
```

| 词界 + 作用域 | 1,878 | 102 | 86 | 16 | 18 | 34 / 1 | 143 / 159 |
