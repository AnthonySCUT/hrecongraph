# 第 16 批：多片段证据、按需句子定位与条件双锚点

## 核心改动

本批串行验证三个机制：完整收集派生语义槽的来源证据、在命中轮次内按需定位句子、在同一写入状态上比较 Top-1 与条件 Top-2。写入继续按段落组织依赖；句子负责定位来源，段落负责展开依赖。

```text
原文 → 触发词实际起止位置 → 收集各次触发 → 段落事实—依赖绑定
问题 → 固定命中 Session → Top-1 / 条件 Top-2 原始轮次
     → 按需句子定位 → 段落依赖展开 → 原始轮次窗口并集 → 上下文
```

`slot_mode='all'` 为本批默认提取方式；`first` 保留历史首匹配对照。语义槽摘要沿用原有触发词优先级，`source_spans` 保存各次触发的证据位置。显式限定与因果绑定继续确定对应槽位。

500 题采用第 14、15 批同一 LongMemEval Oracle 文件，SHA256：`821a2034d219ab45846873dd14c14f12cfe7776e73527a483f9dac095d38620c`。七种变体分别运行全文和 `w=0/1/2`，共 14,000 条逐题装配记录。各变体先完成装配，再读取 `answer/has_answer` 评分；该数据用于配置探索。

| 文件 | 改前行为 | 改后行为及研究作用 |
|---|---|---|

| `memory/relinking.py` | 句子方案预先保存全来源句子事实片段 | 新增 `locate_fact_sentences()`，仅对命中轮次定位句子，保留原始偏移与段落依赖索引 |
| `examples/evaluate_longmemeval_read.py` | 支持规则与粒度消融 | 增加槽位模式和按需定位参数，记录定位耗时与锚点；Top-2 沿用 0.5 相对得分和 2 个独立实词阈值 |

```python
    def locate_fact_sentences(self) -> dict[str, list[SourceSpan]]:
        """Locate sentences in retrieved fact turns while retaining paragraph dependencies."""
        located = {}
        ranker = MemoryUtilityRanker()
        words = ranker.tokenize(self.query)
        for episode in self.source_episodes:
            content = self._source_text(episode.content)
            selected = set(
                self.source_fact_indices[episode.uuid]
                if episode.uuid in self.source_fact_indices
                else self.source_indices(episode)['fact']
            )
            anchors, cursor = [], 0
            for index, unit in enumerate(self.source_segments(episode)):
                start = content.find(unit, cursor)
                cursor = start + len(unit)
                if index not in selected:
                    continue
                sentences = SemanticStateConstructor._sentences(unit, [episode.uuid])
                anchor = max(sentences, key=lambda span: len(ranker.tokenize(span.text) & words))
                anchors.append(
                    anchor.model_copy(
                        update={'start': start + anchor.start, 'end': start + anchor.end}
                    )
                )
            located[episode.uuid] = anchors
        return located
```

def test_multi_span_slots_retain_repeated_triggers_and_previous_word_boundary_evidence():
    text = 'Atlas recently launched.\n\nAtlas now stores reports.\n\nAtlas now serves queries.'
    memory = UnifiedMemoryUnit(user_id='u1', layer='M1', raw_content=text)
    previous = SemanticStateConstructor('fact_scope', slot_mode='all').construct(memory)
    first = SemanticStateConstructor('word_form_scope', slot_mode='first').construct(memory)
    complete = SemanticStateConstructor('word_form_scope').construct(memory)

    def temporal(state):
        return {span.start for span in state.source_spans if span.field == 'temporal_scope'}

    assert temporal(first) == {text.index('recently')}
    assert temporal(complete) == temporal(previous) | {text.index('recently')}
    assert len(temporal(complete)) == 3
    assert all(text[span.start : span.end] == span.text for span in complete.source_spans)

### 三步机制贡献
